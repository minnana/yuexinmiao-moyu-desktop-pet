# 月薪喵摸鱼桌宠

一个用 C#、.NET 8 和 WPF 编写的 Windows 桌面宠物。在桌面陪你上班，按排班显示秒薪与余额，也能跟着键盘输入抬手、敲键。

普通模式播放 GIF 动画；工作时，头顶的收入提示每秒弹跳一次。余额支持负数，可随时重新设置。

## 功能

- **桌面陪伴**：透明、置顶窗口，拖动猫咪即可移动；普通模式按 GIF 自带的帧延时播放。
- **秒薪与余额**：填写税前月薪、月休天数、班次和午休；在可计薪时段累计余额，收入提示约每秒刷新。
- **灵活排班**：支持指定休息日、加班时段、加班倍率和跨午夜班次。
- **可修改余额**：支持负余额，保存设置后从新余额继续累计。
- **键盘跟随**：按下时落手，松开任意按键时抬手；显示最近按键，并在银白色键盘上提供高亮反馈。
- **大小设置**：默认 65%，支持 40%～150%。
- **托盘菜单**：打开窗口、切换键盘模式、暂停或继续计薪、退出。
- **开机启动**：可选择随当前 Windows 用户登录启动。
- **本地保存**：记录余额、排班和设置；未暂停时，下次启动会按已保存排班补计关闭期间的收入。

## 运行程序

面向 **Windows x64**。自包含发布版只需运行 `YueXinCat.exe`，使用者无需安装 .NET SDK 或单独安装 .NET 运行时。

- [下载发布版](https://github.com/minnana/yuexinmiao-moyu-desktop-pet/releases/latest)
- [查看源码与问题反馈](https://github.com/minnana/yuexinmiao-moyu-desktop-pet)

1. 将发布版 exe 放到一个固定目录并打开。
2. 点击齿轮，设置当前余额、税前月薪、工作时段、午休和休息日。
3. 点击“键盘跟随”切换模式；拖动猫咪调整位置。
4. 通过面板上的 `×` 或托盘菜单退出；关闭前会保存当前余额。

启用开机启动后，请保持 exe 路径不变。移动程序后，在设置中重新关闭、开启开机启动，以更新启动路径。

## 计薪规则

```text
当月工作日数 = 当月自然日数 − 每月休息天数
每日净工作时长 = 班次时长 − 与班次重叠的午休时长
基础秒薪 = 税前月薪 ÷（当月工作日数 × 每日净工作秒数）
收入增加 = 可计薪秒数 × 基础秒薪 × 对应时段倍率
```

例如：某月 31 天、月休 8 天、税前月薪 ¥10,000，班次 `09:00–18:00`、午休 1 小时：

```text
工作日数 = 31 − 8 = 23 天
每日净工作时长 = 9 − 1 = 8 小时
基础秒薪 = 10,000 ÷（23 × 8 × 3,600）≈ ¥0.015097
```

余额保留小数秒的计算精度，界面显示到分。头顶提示显示固定的基础秒薪，约每秒弹跳一次；因此低秒薪时，显示到分的余额可能隔数秒才变化。系统繁忙时界面刷新可能稍有延迟，累计金额仍按实际经过的可计薪时间计算。

### 休息日

“月休天数”用于计算秒薪分母；“固定休息日序号或日期”用于决定具体哪天停止常规计薪。这两项需要分别填写。

```text
1, 2, 9, 10, 2026-10-17
```

- `1` 表示每月 1 日休息；`2026-10-17` 表示仅这一天休息。
- 可使用逗号、分号或换行分隔。
- 不会根据月休天数自动选定休息日期，也不会自动导入周末、法定节假日或调休安排。
- 指定的休息日期数量与月休天数不一致时，程序仍分别按上述规则处理；请按自己的实际排班保持一致。

### 午休与跨午夜班次

班次结束时间早于或等于开始时间时，按次日结束处理；开始、结束相同意味着 24 小时班次。午休只扣除与该班次实际重叠的时间。

例如 `22:00–06:00` 表示当日 22 点上班、次日 6 点下班。次日凌晨仍属于前一天开班的班次，是否休息也按开班日期判断。

### 加班

每行一个时段，格式为：

```text
日期 开始时间-结束时间 倍率
2026-10-27 19:00-21:00 1.5
2026-10-28 22:00-02:00 2
```

- 省略倍率时，默认为 `1.5`；倍率 `0` 的加班记录不产生收入。
- 加班可发生在休息日，也支持次日结束。
- 同一开班日期的常规时段与加班时段重叠时，重叠部分取最高倍率，不叠加支付。
- 当前余额计算包含加班倍率，但面板和头顶的“每秒”提示显示基础秒薪。
- 这是按自定义排班计算的收入展示工具，不包含税费、社保或企业考勤结算规则。

## 从源码开发

需要 Windows 和 **.NET 8 SDK**。可使用 Visual Studio、VS Code 或命令行；项目未引用第三方 NuGet 包。

在项目根目录运行：

```powershell
dotnet restore .\YueXinCat.csproj
dotnet build .\YueXinCat.csproj --configuration Release
dotnet run --project .\YueXinCat.csproj
```

发布 Windows x64 自包含单文件程序：

```powershell
dotnet publish .\YueXinCat.csproj --configuration Release -p:PublishProfile=win-x64
```

也可执行项目内的构建脚本：

```powershell
.\build_windows.ps1
```

发布结果位于：

```text
bin/Release/net8.0-windows/win-x64/publish/YueXinCat.exe
```

SDK 仅用于开发和构建；分享给朋友时，发送自包含发布版 exe 即可。

仓库的 Windows build 工作流也会在推送后构建并发布可下载的构建产物，详见 [Actions](https://github.com/minnana/yuexinmiao-moyu-desktop-pet/actions)。工作流验证构建与打包；桌面动画和键盘交互仍需在 Windows 上手动验证。

## 数据与键盘隐私

余额、排班和设置保存在当前用户的本地文件：

```text
%APPDATA%\YueXinCat\state.json
```

程序约每 5 秒及退出时保存一次。备份或迁移设置时，请先退出程序，再复制这个文件。该文件是普通 JSON，包含你填写的月薪和余额，请勿上传到公开仓库或直接附在 Issue 中。

键盘跟随使用 Windows 低级键盘钩子接收按下、松开事件，只用于当前按键名称和动画反馈。关闭键盘跟随会卸载钩子；当前代码不保存按键历史，不模拟输入，也不包含网络上传或遥测逻辑。键盘钩子受 Windows 会话和权限边界影响，安全桌面等环境下可能无法获得事件。

开机启动写入当前用户的注册表项，无需管理员权限：

```text
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
值名：YueXinCat
```

## 当前限制与反馈

- 暂无自动节假日排班、云同步、多设备同步或自动更新。
- 键盘贴图只为部分字母键和空格配置了独立高亮位置；其他键通过中央按键标签反馈，不能对应完整实体键盘布局。长按键也会在短暂落手后自动复位，作为漏收松开事件时的保护。
- 秒薪按自然月重新计算；涉及跨月班次、系统时间或时区变化的复杂排班，建议核对结果。
- 当前仓库没有独立的自动化测试项目。提交修改前，请至少运行 Release 构建，并检查普通模式 GIF、收入提示、键盘按下与松开、设置保存及托盘退出。

反馈问题时，请附上 Windows 版本、程序版本或提交编号、复现步骤，以及隐去个人金额等信息的截图。涉及计薪问题时，可用虚构金额提供班次、午休、休息日和加班示例。
